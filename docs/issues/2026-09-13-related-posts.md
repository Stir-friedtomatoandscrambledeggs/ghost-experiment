# Issue：文章详情页“相关推荐”（按同标签推荐）

- 分支：`feature/blog-enhancement`
- 类型：功能增强（非换色、非文案替换，含取数逻辑变化）
- 提出日期：2026-09-13

## 背景 / 问题

默认主题 Casper 在文章底部用 `{{#get "posts" filter="id:-当前文章"}}}` 取**全站最新**文章，
读者看完一篇技术文章后，被推荐的可能是完全不相关的生活随笔，不利于连续阅读。

## 目标

详情页底部根据当前文章的**主标签（primary_tag）**推荐最多 3 篇同标签文章，并排除当前文章；
无主标签时回退为“最新文章”。推荐结果可通过 Content API 复核。

## 验收标准

1. 打开任一含标签的文章，底部出现“相关推荐 · 标签名”，最多 3 张卡片。
2. 推荐文章的主标签必须与当前文章一致，且不包含当前文章本身。
3. 无主标签的文章回退为最新文章列表，不出现空白。
4. 通过 Content API 用相同过滤条件可复算结果，纳入自动化测试。

## 实现要点

- 仅改主题 `post.hbs`（取数 `filter="primary_tag:<slug>+id:-<id>"`）与少量 CSS，
  不改 Ghost 核心、不依赖额外服务。
- 关联提交见本分支 commit；合并方式：Pull Request / `--no-ff` 合并。
